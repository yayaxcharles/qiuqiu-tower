# 右上動作展示的狀態與收尾修正

日期：2026-09-20。

使用者確認問題位置是右上「動作展示」。之前檢查左側戰鬥角色，沒有覆蓋這個獨立播放器，兩者不能互相當作通過證據。

## 查到的實際情況

- 中毒、翻肚、炸毛、隱身素材都還在。修正前的右上炸毛實際仍循環播放八格，沒有重現所有狀態素材失效，不能聲稱已修復不存在的素材刪除。
- 右上展示原本只呼叫 `actor.play()`；普通攻擊等非循環招式播完後保持尾格，沒有接回待機呼吸。
- 隱身透明效果只套在戰鬥 `.sprite-box`，右上獨立展示沒有套到。
- 原本角色高度只有 54；新增放大按鈕後可用 220 高度檢視，方便辨認狀態姿勢。

## 修改

- 獨立展示的招式依真正動作時長接回待機呼吸；切換選項、重播、放大、重設與離開時取消舊收尾計時器。
- 中毒、炸毛、隱身依原素材持續循環。翻肚播完保持躺姿，不被一般待機覆蓋；倒地、落敗、勝利與循環移動也保留原有展示語意。
- 隱身套用 0.58 透明度，切換其他動作即移除。
- 可放大或縮小同一個展示舞台，沿用原選項及分身特效；放大區域攔截指標，避免誤點底下魔物。

## 瀏覽器確認

頁面：`http://127.0.0.1:5193/qiuqiu-tower/?motion-preview`。

- 放大翻肚後，已目視完整四腳朝上躺姿。
- 中毒、炸毛、隱身各觀察 2.2 秒：各自記錄八個不同影格，最後使用各自 `generated_poison.webp`、`generated_puff.webp`、`generated_stealth.webp`；隱身透明度為 0.58。
- 四種爪擊依序從右上選單播放：各自經過 `claw_1_sheet.webp` 至 `claw_4_sheet.webp`，再回到 `idle_hurt_sheet.webp`。待機繪製高度持續由約 221.007 增至 224.16–224.77，非停在攻擊尾格。
- 新增十項播放器測試，涵蓋四爪擊與踢擊收尾、四種狀態保留、切換動作取消舊計時器、隱身透明度清除。相關五個測試檔共 160 項通過，正式建置通過。

本次沒有修改卡牌、傷害、狀態優先序或正式戰鬥狀態規則。

## 後續修正：持續狀態抖動

上方是前一輪的確認紀錄。使用者隨後指出狀態仍快速抖動；八格都有播放只證明素材存在，不能證明動作平順。

- 修正前，右上放大隱身在 1.9 秒內切換八個姿勢；繪製高度在 199.709–220 間跳變，水平位置也有約 2.94 像素差異。普通待機的平順呼吸原本只限於 `idle`，這是其餘持續狀態被漏掉的原因。
- `frame-motion.ts` 新增 `restFrames`：球球中毒採掩口不適姿勢，炸毛保留豎毛尾巴，隱身保留噤聲姿勢與既有透明效果；三名同伴中毒也使用自己的掩口姿勢。各狀態固定代表畫格，以 6.2 秒連續呼吸，最大高度變化 2.5%，固定水平位置與落地基準。
- 翻肚先播放完整 910 毫秒躺下過程，之後保持最後一格並緩慢呼吸。畫布邊界納入呼吸幅度，避免頂部裁切。
- 限定原動作與解析姿勢相同才套用休息姿勢，跑步、出招、命中時點與複合招式仍沿用原本畫格和節奏。
