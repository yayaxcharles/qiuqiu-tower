## 這個遊戲三十秒

繁體中文的網頁**牌組肉鴿**（像《殺戮尖塔》）。你是一隻貓忍者，一層一層往上打魔塔。
一場戰鬥用飯糰（能量）打牌，打完敵人才換牠行動。可以一個人玩，也可以**兩個人連線一起打**。

**兩個可玩角色**：

| | 球球 | 菲菲 |
|---|---|---|
| 長相 | 灰虎斑小貓忍者 | 暹羅貓，球球的師妹 |
| 路數 | 蜷縮擋、爪力疊傷害、隱身 | **中毒**＋**攻擊牌自帶蜷縮** |
| 個性 | 直接，衝上去 | 怕痛，先道歉先警告先退開 |
| 起始秘寶 | 藍頭巾（第一回合多抽 1 張） | 毒針袋（每回合開始給所有魔物 1 層中毒） |

## 名詞（設計時會用到的）

| 名詞 | 意思 |
|---|---|
| **飯糰** | 能量。每回合回滿（預設 3 顆），打牌要花。 |
| **蜷縮** | 護甲。抵銷傷害，**下一個回合開始時歸零**。 |
| **爪力** | 力量。每張攻擊牌多打幾點。 |
| **貓步** | 敏捷。每次獲得蜷縮時多幾點。 |
| **中毒** | 每回合開始扣等同層數的血，然後**層數 −1**。所以 N 層的總傷害是 **N(N+1)/2**：10 層＝55、20 層＝210。這條是菲菲全套的基礎，設計跟毒有關的牌一定要先算這個。 |
| **隱身** | 這回合不會被攻擊到。球球專屬路線。 |
| **消耗** | 打完這場就不再回到牌堆。 |
| **壞毛病** | 詛咒牌，塞進你的牌組扯後腿。 |

**牌的三種類型**：`攻`（攻擊）、`技`（技能）、`能`（能力＝這場戰鬥持續生效）。

**三種稀有度**：常見 → 罕見 → 稀有。越稀有越強也越少出現。

## 設計新牌的規矩

1. **先算數字再寫文案。** 中毒那條公式最容易低估：給 3 層看起來很少，實際是 6 點傷害，
   而且能疊。
2. **升級版不要只是「數字大一點」。** 好的升級是**改變用法**（例如基礎版只擴散一半毒、
   升級版擴散全額）；只加 1 點傷害的升級玩家不會有感覺。
3. **看起來弱的基礎版，要先看升級版給了什麼。** 這是這個專案犯過的錯——
   把基礎版調強，結果升級版變得沒意義。
4. **名字走口語路線**（「我在這」「交出來」「先睡了」「分你一半」），不取武功名。
   角色專屬牌可以有招式名（「絕學·亂針」），但連線牌是**跟同伴講的話**，
   用招式名反而隔了一層。
5. **菲菲不說「喵」**，球球才說。菲菲的口頭禪是「那個……」開頭、「我有先提醒你喔」。
6. 不要寫「回合數」以外的計時器、不要設計需要玩家記憶多回合前狀態的機制——
   這是網頁小品，不是硬核遊戲。

## 這次要你做什麼

**多想幾張「連線專用牌」**（第一節那些）。現有 9 張分三條線：

- **防禦**：分你一半、你拿去擋、你先躲、我來擋
- **進攻**：幫你一把、借你踩兩步
- **節奏**：你也抽一張、我幫你拍掉、飯糰分你

規格：

- **必須是「因為有同伴才成立」的效果**：把資源、狀態、保護給對方，或用對方的狀態換自己的好處。
  一個人玩也能用的就不算。
- 一個人玩的時候要能**退化成作用在自己身上**，不能變成廢牌
  （牌可能從事件流進單機的牌組）。
- 每張要有：**牌名**（3～6 字口語）、**費用**、**類型**、**稀有度**、
  **效果一句話**、**升級後**、以及**一句話說明為什麼這張牌有趣**。
- 不要寫程式碼、不要碰檔案，只要交文字。
- 效果盡量用現有的積木（下面表格裡看得到的那些）。真的需要新機制就標註
  「**這張需要新效果**」並說清楚它要做什麼。
