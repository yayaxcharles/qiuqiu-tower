## 4. 本機兩分頁連線試玩（混搭角色）

做法：
- 用合併後的程式另外打一包，中繼網址指向本機的 `wrangler dev`，由本機伺服器（連接埠 5287）提供。
- 開兩個無頭瀏覽器，各用自己的設定資料夾（`visual-gate/lib/browser.mjs`），連同一台本機伺服器。
- 開房的那邊網速不限。加入的那邊冷快取，並用瀏覽器除錯介面模擬 **0.8 Mbps／300 毫秒**。
- 自動點擊的方式：地圖兩邊投同一格（優先選戰鬥格），戰鬥照手牌出牌、打完就結束回合。**完全不作弊、不改血量**，一改兩邊就會對不上。
- 對照的方法：
  - 每次兩邊都回到地圖、還沒投票時，比一次**整局指紋**（整個局面資料的雜湊值）。
  - 每場打完當下，比兩邊的**戰鬥紀錄全文**、魔物與主角的最終狀態。
- 腳本在暫存區（`coop_play.mjs`），沒進倉庫。
