# 噹噹：戰鬥動作側面修正版

使用者修正：戰鬥畫面是側面，上一版噹噹太朝向鏡頭。

這版參照目前遊戲戰鬥使用的球球素材 `hero/ninja`、`hero/ninja_punch`、`hero/ninja_guard`：頭臉朝右、只露近側眼睛、出招沿畫面左右方向展開。保留噹噹原有黑白花色、青綠短褂及銅護臂。

共五張獨立 PNG。上一版保留於原資料夾，本次沒有修改遊戲程式。圖像為淺米白背景的單張動作概念稿，尚未去背、拆層或製作連續動畫。

生成方式：內建圖像生成工具。每張使用球球站姿、球球出拳或格擋、對應噹噹上一版動作圖三個參考。

## 完整繪圖提示

完整提示由共用段、文字「本張指定動作：」及各動作段依序組成。

### 共用段

```text
修改既有「噹噹」戰鬥動作圖的鏡頭與朝向，讓他適用於和球球相同的橫向對戰畫面。

參考圖角色分工嚴格如下：參考圖 1 的灰色藍衣貓是「球球」，只用來學習遊戲戰鬥鏡頭與頭部側面朝向；參考圖 2 也是球球，只用來學習側向出招和前後手的空間關係。絕對不要把這兩張圖的灰毛、條紋、藍頭帶、忍者服或臉型加到噹噹身上。參考圖 3 是本次真正要改的「噹噹」原圖，保留他的角色外型、衣服、配色、護臂和二維畫風，將原本朝觀者的斜側面改為朝畫面右方的側面戰鬥姿勢。

最高優先要求是純粹的側向閱讀：噹噹的頭與鼻尖指向畫面正右方，只能看見一隻近側琥珀眼睛，遠側眼睛完全被頭部遮住。鼻子位於臉部最右側的輪廓上，吻部側向伸出，不能把鼻子畫在兩眼中間。從鏡頭看只見一邊臉頰。禁止正面、禁止前側四分之三臉、禁止轉頭看觀者。頭、肩、胸口、髖部與腳尖都以面向右方為主；近側肩膀與近側護臂在前，遠側手臂自然在後，身體朝右、不向鏡頭攤開胸口。縱深可略作遊戲立繪式的簡化以看清四肢，但不能為了同時展示兩個護臂而把整個胸口轉成正面。戰鬥動作主要在畫面左右方向展開，拳頭向右，不能向觀者伸出。保持固定的平視側面鏡頭，無俯視、無透視廣角。

噹噹身分全部保留：黑白花色、黑色大圓頭、短三角貓耳與粉紅內耳、原有白色額鼻花紋在側面只露出輪廓邊緣、白口鼻與白爪白腳、一隻可見的金色眼睛、粉紅小鼻子、敦實短壯但靈活的貓身材、一條黑色貓尾自然長在骨盆後方。灰青綠無袖中式短褂、米白滾邊、原有兩個深棕盘扣，盘扣按侧向透视自然可见或被遮住，不能为了完整展示盘扣而把胸口转向镜头；深棕布腰帶、深灰寬褲、腳踝綁布。每邊前臂都有同一套古銅圆弧護臂與深棕皮扣帶，側面不改成拳套或手拿盾。白色手掌必須自然連接手腕、伸出護臂末端。只有兩手兩腳一尾。手掌大小相同，肩肘腕和前後遮擋要合理。

保留原噹噹圖片的粗深色輪廓、簡潔賽璐璐陰影、少量銅面質感與可愛表情，不要改成球球的外觀。正方形單張、單一角色、完整全身，耳朵尾巴手腳與完整動作都不要裁切，四周留至少 8% 空白。純淺暖米白背景與小小接地陰影，不畫場景、敵人、文字、格線或多格比較。不要直接貼球球，不要把兩隻貓混在一起。

```

### 01_攻擊

第二張參考圖：`ninja_punch.webp`。

```text
側面攻擊：像球球側向出拳那樣，貓的側臉看向正右方且只有一隻眼。前腳向畫面右方大踏一步，前膝彎曲、後腿向左蹬地，身體朝右前移而不朝觀者扭開。出拳手沿畫面水平向右伸長，拳頭距身體外緣約一個頭寬，手肘自然接近伸直、白拳清楚露出銅護臂。另一手彎肘收在腰側到胸口之間，不藏到背後、不多長一隻手。頭髮與衣服全部保持噹噹原造型。嘴巴小幅張開吐氣，腰帶與尾巴往左後方帶起。可以有兩條短淡青拳風，但不能遮擋手臂。畫面看起來是側面格鬥遊戲裡面對右方敵人的出拳。
```

### 02_格擋

第二張參考圖：`ninja_guard.webp`。

```text
側面格擋：頭鼻與胸口朝畫面正右方，只有近側一隻眼可見。身體低沉、前後腳沿左右方向分開承重；右前方是敵人方向。兩隻戴護臂的前臂架在胸口前、鼻子前下方，近側護臂清楚地豎起，遠側護臂稍往右前方錯開、按側面角度自然部分被遮住，不要並排成面向觀者的兩面盾。手肘彎曲朝下，手腕在下巴以下，肩膀到手腕關係合理，兩隻白爪自然露出。臉從護臂上方露出，專注地看正右方。胸口沒有向鏡頭攤開，肩膀不是正面水平並排。沒有任何能量盾或攻擊特效。這是側面視角下確實護住敵方來襲方向的雙臂防守。
```

### 03_反彈

第二張參考圖：`ninja_punch.webp`。

```text
側面反彈：頭鼻完全指向畫面右方，只有一隻側面眼睛。低重心前後弓步，面向右方的肩膀帶動近側屈肘手臂向右推擋，銅護臂凸面承接來襲衝擊。手肘保留自然彎度，白色拳頭清楚露在護臂上緣或末端，不能被畫成銅色或消失；另一手收在胸前至腰側，按正確側面遮擋只露必要輪廓。表情專注略帶得意。護臂最右側有小金色碰撞火花，一道橙色短入射痕跡由右向左止於銅面，另一道青綠金邊彎月弧線從銅面返回右上方，來去軌跡錯開且都不能穿過手掌。沒有箭頭符號，效果只在護臂前方局部，所有光弧也留在畫面內。不要把這個反彈姿勢畫成對觀者出拳。
```

### 04_蓄力

第二張參考圖：`ninja_guard.webp`。

```text
側面蓄力：頭、吻部與唯一一隻可見金眼朝正右方，不回頭看觀者。降低重心，兩腳沿畫面左後與右前方向分開，而不是正面左右對稱馬步；軀幹主要側向右方，肩膀一前一後有遮擋。兩隻手肘收向後，近側的白拳與銅護臂低低收在腰部前側，遠側拳頭在胸腹前方自然局部可見；不要把兩隻護臂對稱展示在畫面左右，不要把胸前盤扣轉正面。目光專注、嘴巴緊閉。銅護臂邊緣有微弱青金光澤和幾顆小亮點，腳邊一圈淡淡氣流，腰帶和尾巴微揚；沒有能量球、沒有巨大法陣。這是側面遊戲角色蓄力，依靠低站姿、手臂收勢與克制光澤辨認。
```

### 05_受擊

第二張參考圖：`ninja_guard.webp`。

```text
側面受擊：畫面右方是受到攻擊的方向，角色原本面朝正右方，現在胸口與頭向左後方傾斜卸力，鼻尖仍指向右上方；保持側臉輪廓，只有一隻近側眼睛，因疼痛閉成一條弧線，不能露出第二隻眼。近側耳朵稍向後壓，嘴巴張開小幅驚呼。身體侧向後仰，右前脚因冲击滑动、左后脚踏住支撑，前後腿按侧面空間關係摆放。近側手臂彎肘保護腹部，另一手被震到胸前外側、仍在身體朝向的右方，兩個銅護臂都固定在各自前臂、手腕白爪自然相連，不要張開雙臂面向觀者。腰帶和尾巴順慣性向右，腳旁少量滑動短線。服裝護臂完整，無流血傷口、無敵人、無大火花、無星星。這是站著被打退的一瞬間，不是跌倒或死亡。
```
