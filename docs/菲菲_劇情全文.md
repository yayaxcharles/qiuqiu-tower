# 菲菲的劇情（現況全文）

> 設定：球球的小師妹、大俠貓最小的徒弟，晚三年入門。力氣不大，正面硬碰硬沒勝算，所以專練飛針、在針上淬藥，靠連續命中把毒一層層疊起來。極度怕痛，習慣是「先下毒、再撤開、等對方自己倒」。講話容易緊張、常用「那個……」開頭，**不加「喵」**。對手中毒後會小聲補一句：「我有先提醒你喔。」

### 序章（開局四張圖配四句）

- *（旁白）* 菲菲比球球晚三年入門。師父教球球的是怎麼把人打倒，教她的卻是另一句：「力氣小，就別跟人比力氣。讓他碰不到你，照樣能贏。」這句話，她記得比誰都牢。
- *（旁白）* 那天夜裡，魔塔在村外拔地而起。紫光落下來，大俠貓渾身毛髮豎起、雙眼染紫，一言不發衝進塔頂。球球抓起頭巾就追了上去。
- **菲菲**：……三天了。師父沒回來，師兄也沒回來。
- **菲菲**：那個……我真的很怕痛。可是再等下去，好像就只剩我能去找他們了。

### 打完第一關關主（塔下 → 塔中）

- *（旁白）* 守關的魔物倒下，牆邊露出一道往上的樓梯。地上散著幾根被踩彎的針——不是她的。
- **菲菲**：這是師兄的頭巾線頭……他真的上去了。等等，他到底一路撞了多少東西啊……
- *（旁白）* 菲菲低頭補了一層藥，將飛針一根根插回竹筒，才貼著牆往上走。她沒有跑；手抖的時候，跑也丟不準。

### 打完第二關關主（塔中 → 塔頂）

- *（旁白）* 魔物化成煙散去時，塔頂傳來一聲長喵——熟悉得讓她整條背脊都僵住了。
- **菲菲**：那是師父的聲音……那師兄呢？師兄為什麼沒有回話？
- *（旁白）* 月光落在最後一段樓梯上。她深吸一口氣，把口罩拉了上來，又摸了摸竹筒裡剩下的針。
- **菲菲**：毒還夠……針也夠。那個……應該，夠吧。

### 陣亡

- *（旁白）* 菲菲的竹筒空了。最後一根飛針落在幾步外，她背靠著牆滑坐下去，手還在發抖。
- **菲菲**：說好……不要靠近我的……
- *（旁白）* 恍惚間，有人把她背了起來。再睜眼時，她已經躺在村裡，膝蓋上放著一把重新磨好的針，旁邊還擺著一小瓶新調的藥。魔塔依然站在那裡。
- **菲菲**：……下次我要多塗一層。

### 通關

- *（旁白）* 最後一縷魔氣從師父身上散去，他眼中的紫光終於熄滅。塔頂的另一頭，一團灰色的東西動了一下——是球球，還在喘。
- **塔主**：承讓。
- **菲菲**：……我、我沒有很厲害。我只是先讓你們中毒，再一直丟、一直退……等你們自己撐不住而已。
- **菲菲**：而且……我有先提醒你們不要過來喔。
- *（旁白）* 師父把她拉過去，摸了摸她的頭。她愣了三秒，才開始掉眼淚——手裡還緊緊捏著最後一根沒丟出去的針。
- *（旁白）* 下山的路上，球球一路吵著要吃小魚乾，師父笑得很大聲。菲菲走在最後面，一根一根把能撿回來的針收進竹筒裡。三個都回來了。
