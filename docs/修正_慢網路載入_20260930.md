## 4. 沒做到、量不到、有風險的

1. **正式站 GitHub Pages 的優先權排程量不到**。HTTP/2 本機模擬不照優先權排，所以 HTTP/2 那兩格的蓋層撞滿 8 秒上限、進去之後底圖還缺 2.0～5.3 秒（修正前一片黑 13.5～15.3 秒）。正式站若有照優先權排，應接近 HTTP/1.1 的數字；若沒有，慢網路玩家會先看到 8 秒進度條。
