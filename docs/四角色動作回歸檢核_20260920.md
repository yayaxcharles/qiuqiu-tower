# 四角色動作回歸檢核

日期：2026-09-20。接續 `147f624` 後的使用者實際回報，這份紀錄取代前一輪對受擊與效能改善幅度的判斷。遊戲數值、卡牌效果與正式存檔未變動。

## 根因與修正

1. 前一輪只延長反應的總時間，但封封、噹噹真正痛苦的影格只有約 165 毫秒。四隻統一使用原有受擊立繪，持續 650 毫秒，配合遞減抖動與紅閃；每次受擊重新計時。共用原本的動作生命週期，不另設第二套計時器。
2. 偷吃術沒有接上吃飯動作，升級版又因抽牌落到卷軸；鮪魚、溫牛奶也漏在食物忍具名單外。已補足動態與靜態備援。
3. 菲菲、封封的通用動作覆蓋了既有吼叫、輕功、太極立繪；包含攻擊牌獅吼功與借力使力。保留明確的角色專用對照，其餘交回既有專用立繪。
4. 連續出牌改用靜態招式時，舊動作仍遮住新圖，收尾還會把新姿勢換成待機。現在明確出新招時收掉舊動作；一般更新、同伴行動及延後確認保留原反應。
5. 回血結算無條件改成吃飯，會再次蓋掉太極與反擊。現在尊重本張牌或忍具已選好的演出；同樣保留靜態自傷招式的出手姿勢。
6. 四隻待機呼吸每次螢幕更新都重新繪製大畫布。呼吸改為在固定腳底縮放既有畫格；相同畫格不重畫，脫離 DOM 後略過繪圖，重新掛回追上原時間軸。
7. 標題尚未選角就預載球球全部動作，選其他角色仍先載入約 25.6 MiB 的球球圖集與投射物。改在新局、續玩及雙人角色確定後，只暖本局角色。
8. 封封五張原狀態圖確實有不透明灰霧、另一隻貓的耳朵、缺腳或腿部透明缺口。以內建影像生成工具修補原姿勢，另存 `fengfeng_*_clean.webp`，保留舊檔；修正五條素材路徑。另依實際透明底邊校準封封靜態姿勢，避免隱身、負面狀態飄離地面。
9. 正式站驗證另抓到打包問題：四張受擊圖已有立繪分類鍵，雜湊外掛因此省略原路徑對照，但逐格動作是透過原路徑載入，造成正式版解碼失敗。已把這四張共用圖加入原路徑對照；新增測試以真實圖片及打包外掛重現四隻全部失敗，再確認修後四隻都能載入帶雜湊檔名。
