## 推送前發現與處置

| 問題 | 處置與驗證 |
|---|---|
| 老鼠待機與受擊被錯誤翻轉 | 按動作設定鏡射，固定腳底；動作方向與支點測試、實際戰場確認 |
| 赤鬼受擊圖原本朝右，正式建置又改了圖名 | 單獨鏡射受擊圖，同時匹配原名與雜湊名；正式建置頁確認 `red_oni_hurt-pJ9G2R_k.webp` 在震動時仍為 `scale: -1 1` |
| 合作單張出牌的延遲確認遺失近戰行程 | 保存並傳回原始行程；520 毫秒預演結束、600 毫秒確認到達時仍在原目標旁完成連打 |
| 倒下隊友被叫起來播放勝利 | 勝利演出排除倒下席；兩個席位交替倒下的案例均通過 |
| 菲菲見血封喉消耗封封支援卻沒有加傷 | 接回共用加成入口；確認倍傷只套一次、不吃爪力、忽略蜷縮、中毒層數不變，無毒不強造命中 |
| 零反彈的原樣奉還被支援強造傷害 | 零基礎值不建立傷害；0 與 2 反彈均有回歸。正常起手有銅護臂，零反彈主要涉及匯入局面 |
| 首載失敗被記成已預載 | 只登記成功圖片，包含沒有 `decode()` 的退路；兩次失敗後第三次遭遇預熱成功的案例通過 |
| 延遲畫面載入失敗只有文字 | 加上重新整理按鈕，保留舊請求與離場守衛；按鈕實際呼叫重新整理的測試通過 |
| 完整動作啟動器沿用單人名稱的本機路徑 | 改為呼叫合作版共用啟動器；`-NoBrowser` 實際回傳 `http://127.0.0.1:5192/qiuqiu-tower-coop/?motion-preview` |
| 歷史生圖工具缺來源，或仍檢查已被替換的舊素材 | 12 支歷史封裝／入庫腳本與 28 個工作素材檔留在本機，不納入本次提交。正式素材、清單、程式、測試與稽核紀錄全部納入；未覆寫目前已接受的圖片 |

兩個提案資料夾的 750 個未整合檔案亦留在本機。本次保留既有版本管理忽略規則，沒有刪除原稿、修改單人版或把原稿混入遊戲部署。

- 本輪針對新增缺陷先重現失敗，再驗證最小修正；完成後重新執行全套測試與合作版建置。
