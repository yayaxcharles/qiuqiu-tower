## 一、推送為什麼一直失敗（已修，`ba88e95`）

9/13 一天部署紅了八次，線上停在凌晨那版一整天。病根兩種：

- **推出去的東西本身就是紅的**：沒跑完測試就推；看測試結果用 `tail -3` 把紅字截掉
- **推完只看 `git push` 成功就說上線**，沒等雲端跑完、也沒看線上真的換了

修法：

- `tools/prepush_gate.sh`（由 `.git/hooks/pre-push` 呼叫）：推到 `main` 之前另開一個暫時工作目錄、
  只放要推的那一筆，跑跟雲端一樣的測試與打包，紅了就擋下來（在工作目錄跑會漏掉「新檔忘了 git add」）
- `tools/deploy.sh`：推 → 等 Actions → 比對線上主程式檔名
- **以後部署一律 `sh tools/deploy.sh`**，不要手動 `git push coopdeploy coop:main`
- ⚠️ `pre-push` 鉤子不在版控裡（`.git/hooks/` 不會被提交），換一台機器要重裝。
  這台裝在 `F:\ClaudeWork\qiuqiu-tower\.git\hooks\pre-push`（兩個工作目錄共用），內容：

  ```sh
  #!/bin/sh
  gate="$(git rev-parse --show-toplevel)/tools/prepush_gate.sh"
  [ -f "$gate" ] || exit 0
  exec sh "$gate" "$@"
  ```
