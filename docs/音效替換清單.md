# 音效替換清單（26 個）——免費可商用來源

> 2026-09-02 整理。現在的 26 個音效是程式合成的（`tools/make_sfx.py`），品質有限。
> 替換方式：從下面來源載 mp3 →**改成同檔名**→ 丟進 `public/assets/sfx/` 覆蓋即可，程式一行都不用改。
> 音量若不合，`src/ui/audio.ts` 的 `GAIN` 表可以按檔微調。
