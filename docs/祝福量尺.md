# 開局祝福量尺（機器人實測）

> 由 `tools/relic_ruler.test.ts` 產生（`RULER=bless npx vitest run tools/relic_ruler.test.ts`），不要手改。2026-09-23。
> 每一格：開局**強制拿這一樣**（不管包袱裡有沒有）、這隻跑 600 局（種子 `ruler-0`～、難度 1），跟「什麼都不拿」的同一批種子逐局相減。
> 括號是標準誤；差距小於兩倍標準誤的標「≈」＝量不出差別。過一關／過二關／通關是比例差（百分點，四隻平均）。

> 舊護腕 `bless_bracer` 那一列：那件秘寶（`master_bracer`）是稀有事件那條線（b3rare）做的，量的時候這個分支還沒有，照 b3rare 定案的同一件（每場開始 3 點爪力與 2 層翻肚）臨時塞進來量；合併之後重跑一次 `RULER=bless` 就會換成正式量的數字。
