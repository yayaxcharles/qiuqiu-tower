# 《爪破魔塔：球球參上》設計總覽

> 階段性整理，2026-09-01。涵蓋目前已上線的所有機制與設計決定，
> 以及尚未動工的方向。線上版：<https://yayaxcharles.github.io/qiuqiu-tower/>

## 一、定位

灰貓忍者「球球」（來自作者的 LINE 貼圖角色）爬一座魔物塔的牌組構築肉鴿，
玩法對標《殺戮尖塔》。純靜態網頁、免安裝、存檔在瀏覽器。
名稱 2026-09-01 定案：中文《爪破魔塔：球球參上》，英文 Clawbreak Tower: Qiuqiu Arrives。

## 二、核心循環與三關制

- 一條命打三關：**塔下（1–15F）→ 塔中（16–30F）→ 塔頂（31–45F）**，牌組、秘寶、忍具、小魚乾全程繼承，死了整局結束。
- 每關一張節點地圖（五車道、三條路線、可重疊）；打倒關主 → 過場對白 → 過關畫面（**回滿血**＋大魔物級秘寶三選一＋稀有牌三選一）→ 三秒走路轉場 → 下一關。
- 關主分配：塔下＝貓又婆婆／鐵爪機關貓二選一（將擴充為三選一）；塔頂固定是**走火入魔的大俠貓**（故事的師父，最終頭目；2026-09-02 改三條血制 100／200／250（總計 550）：每條打完蹲下無敵一回合再亮下一條；二階段起有破功（拍散爪力貓步一半）與逐回合成長——師門絕學放大版→走火入魔→深藏不露的蓄力倍擊，每階段有專屬對白）。
- 樓層跨關累計顯示；戰鬥背景一關一個色調（石牢／木造／夜空）。
- 舊存檔相容：載入自動補第一關。

## 三、戰鬥機制

- 資源：**飽足**（能量）每回合 3 顆飯糰；牌型分攻擊／技能／能力。
- 擋傷害的用詞鐵則：球球叫「**蜷縮**」（撐到自己下回合開始）、魔物叫「**防禦**」（撐到牠下次行動）。
- 魔物防禦的節奏：牌子寫「守 N」的當回合身上還沒有，**行動完才掛上**、用來擋玩家下一回合（曾誤判為缺陷，實際是刻意設計，使用者確認後保留）。
- 狀態一覽：爪力／貓步（永久成長）、隱身（整段閃避，消耗制）、潛水（下回合轉隱身）、反彈、定身、翻肚／懶洋洋／炸毛／噎到（回合衰減）。
- 定身（2026-09-02 改）：魔物被定住是**整個動作**做不了（原本只擋攻擊，偷小魚乾、召喚照做），紀錄寫「〇〇被定住了，這回合動不了」；球球被定住仍是攻擊牌鎖住、技能照打。
- 魔物的隱藏機制**全部掛牌可見**（滑鼠有白話說明）：同生共死（復活組）、重生中（倒數）、蓄力、叼著小魚乾、越戰越勇、打倒回血。
- 復活組（影子小貓三人）：倒下顯示半透明殘影＋「重生中 2」倒數，兩回合內清光全部才算數；貓又的尾巴維持一回合復活。
- 單一敵人時，同一張牌連點兩下直接打出。
- **師父 3.0（2026-09-02，使用者定方向：「三個階段沒有看出差異」）**：全程不蓄力。第一條血（120）招招攻擊帶防禦；第二條血（240）傷害明顯拉高、段數多（十二連環 6×7、狂風連掌 11×4、穿心掌 20 穿透），**每回合先震散你 1 點爪力、1 點貓步**；第三條血（300）亡命一擊 22×2 穿透、狂風連掌 8×7、破功／看破配大傷害，**每回合震散 2 點爪力、2 點貓步**（`EnemyPhase.drainPlayerPerTurn`，紀錄寫「震散了你 N 點…」）。每回合 +1 爪力（原本 +2／+3）。三階段各自的出招立繪（`BOSS_MOVE_ART_PHASE`，圖沒生好退回第一階段圖）＋畫面套紅／紫光暈。
- 球球待機姿勢隨狀態換（2026-09-02）：血剩三成以下→掛彩、爪力 ≥5→氣勢（`hero/ninja_hurt`、`hero/ninja_power`，圖沒生好就一般待機）。

## 四、地圖生成規則

- 匯合層：5F 大俠傳功（固定劇情）、8F 紙箱、14F 貓窩、15F 關主——整層單格。
- **查重雙規則**：同一個分岔出去的路不可同型（非戰鬥）；上下層不可連續同型。撞到改成戰鬥。
- 第一關難度守則（2026-09-01 實測後定）：
  - 整關**沒有大魔物**（精英強度是照牌組成形後設計的）；第二關起恢復（含 7F 保底）。
  - 前三層只抽**單隻怪**遭遇。
  - 戰鬥權重調高、事件與商店調降（2–4F 70/22/8）。
  - 弱怪陪到 5F、中型怪 6–10F、強怪 11F+；第二關開場即中型、第三關全程強怪（新怪生好後改各關專屬池）。
- 地圖頂端的關主節點直接用**該局關主的立繪**（110×128，比一般節點大）。
- 地圖狀態語言：**亮的（金光＋縮放）＝可以點的**；站的格子壓暗靜止；走過的更暗。

## 九、回饋設計原則（踩過的坑）

「機制是對的但畫面沒講」曾連續中招：隱身閃避（丟 16 點忍具看似沒反應）、
魔物防禦的延遲、影子復活。原則：**引擎裡玩家看不到的狀態，一律做成畫面上的牌子或飄字**。
現有：閃過！飄字＋煙、防禦「鏘」聲、重生倒數、賭局明講「中了！／沒中……」、
事件戰利品列出圖示與效果、小魚乾即時增減。

## 十、平衡量測方法與現況

- 工具：機器人整局試玩（`playRun`）批次 300 局＋逐遭遇單場探測（典型牌組 60 場勝率）。
- 機器人遠弱於真人，**數字看相對不看絕對**。
- 歷程：平均到達 8.3F →（獎勵改善＋放錯池的兩組殺手遭遇移走）9.2F →（強池 -20%＋常見牌 +1）9.3F；6–7F 死亡數 −34%；32/300 打到第一關關主、全滅於關主。
- 測試基準：兩顆種子的錨值釘在 `tests/engine/bot.test.ts`，機制改動時同步更新並註明原因。
- **2026-09-02 新工具：會算傷害的機器人**（`src/engine/smartbot.ts`）——照真人思路出牌：先看魔物這回合會打多少、擋得住就擋、能收頭就殺、能力牌早放、忍具留到救命或收頭；地圖／獎勵／商店／貓窩／事件也各有一套判斷。報告：`SMART_N=300 npx vitest run tests/smart.report.test.ts`，印通關率、各關到達率、每種遭遇的敗場與掉血、每隻關主的勝率與進場血量（`npm test` 只跑 12 局當煙霧測試）。它比隨機機器人強太多（通關 55% 對 0%），**比新手強、比熟手弱**，拿來找「牆」跟「太軟」最準，絕對數字仍以真人為準。
- 2026-09-02 夜間三刀之後（300 局）：通關 55%；到第二關 87%、到第三關 72%；三關各佔陣亡 13%／15%／17%（改之前 22%／13%／11%——第一關是牆、二三關幾乎沒人死）。關主勝率：鐵爪 83%（改前 50%）、其餘第一二關關主 93～100%、師父 94%（沒動）。
- 2026-09-02 下午（300 局）：補六隻新怪後通關 46.7%（單怪全 0 敗，河童＋木屐 5/61、狐巫女＋紙鶴 4/59 跟其他雙怪組同級）；**師父 3.0 上線後通關 22%、師父勝率 34%（194 場輸 128）、到達第三關 79% 不變**——最終戰現在是真的牆，等真人實打回報再決定要不要放鬆（優先鬆的是三階段的狂風連掌 8×7 與震散 2／2）。爪力量表：打完師父時平均爪力 6.7（3.0 之前 16）。
