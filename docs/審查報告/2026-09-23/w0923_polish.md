# 追加：實機驗收 M-2 閃白（打贏→戰利品那一格米白）

## 原因（實機驗證過，不是猜的）

- `show()` 先把畫面層清空，再讓新畫面從透明淡入 220 毫秒。畫面層底下就是舞台本身，舞台底色是米白（`base.css` 的 `--paper`）。
  - 所以新畫面第一格（完全透明）整片米白；主執行緒一忙，這一格就掛著幾十毫秒。
  - 接著的淡入，前半段也被米白洗過。
- **不是底圖沒解好**：同一套膠卷把淡入關掉再錄一次（頁面載入時注入，原始碼不動），所有換場米白 0 格。
- 關掉淡入後還看到一件小事：第一次進某個事件，底圖第一格還沒畫出來。有淡入時這一格被米白蓋過，看不出來。
- 回地圖是另一個樣子：地圖把舞台底色換成深色，所以是從深色淡入，閃一下黑（亮度跳 60～75）。
