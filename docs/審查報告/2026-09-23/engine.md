## 低

1. **集中精神之後喝「兩顆飯糰」「半卷殘頁」：忍具被吃掉、飯糰 0、紀錄沒交代**（確認）
   - `src/engine/combat.ts:1058`（`canUsePotion` 不看 `energyGainBlockedThisPhase`）＋ `src/engine/actions.ts:147`（`gainEnergy` 靜默回 0）
   - 情境：封封打集中精神 → 同回合喝兩顆飯糰 → 忍具消失、飯糰 3→3，紀錄只有「用了兩顆飯糰」。探針實測確認。牌面寫了「這回合不能再獲得飯糰」，所以規則本身對，只是忍具白白用掉、沒有一行說明。

2. **絕學·藏鋒的牌面沒寫「同名取高」，但引擎會擋第二張**（確認）
   - `src/ui/cardtext.ts:340-348`：`（同名取高）` 只加在 `afterCard` 分支，`turnStart` 分支沒加；`src/content/cards.ts:1016` 藏鋒是 `turnStart`＋`sameNameMax`。
   - 情境：藏鋒已經掛著，再抽到一張基礎版 → 牌變灰（「同名或更高版本的能力已經生效」），牌面卻沒講這條。另外：已掛基礎版時打升級版（升級只降費、效果相同）引擎允許打出、換成一模一樣的能力，等於花一顆飯糰和一張牌什麼都沒多。

3. **退步守勢、看準劍路的門檻句少「至少」和「再」**（確認）
   - `src/ui/cardtext.ts:160`：`出牌前有 ${min} 點蓄氣的話，…`，引擎是 `>=`（`effects.ts:468`）。
   - 實際牌面：「獲得 8 點蜷縮，出牌前有 3 點蓄氣的話，獲得 3 點蜷縮。」——噹噹的 `ifBlock` 同型句有用 `again()` 補「再」，這裡沒有，讀起來像兩次獲得同一份；「有 3 點」也會被讀成「剛好 3 點」。

4. **借我擋一下：單人或同伴倒下時改看自己的蜷縮，但牌面沒有「一個人玩時同伴＝你自己」**（確認）
   - `src/engine/combat.ts:434`（`mateAtPlay` 退回自己）；`src/ui/cardtext.ts:26`（`hasAlly` 對 `ifAllyBlockAtPlay` 只看 `then` 裡有沒有同伴效果，`gainQi` 不算，所以不補句尾那句）。
   - 情境：連線中同伴倒下 → 打借我擋一下，實際判斷的是封封自己的蜷縮，牌面寫「同伴原有至少 8 點蜷縮」。

5. **眼冒金星（0 費技能雜牌）會觸發循息的「每回合第一次打出技能牌」**（可能，看設計意圖）
   - `src/engine/combat.ts:616-625`：`afterCard` 只比 `cardType`，沒排除 `combatOnly`；同一支函式上面的詛咒／憤怒判斷（`combat.ts:605`）有排除。
   - 情境：白狐巫女、鏡仙塞眼冒金星 → 封封掛著循息時打掉它就白拿 1～2 點蓄氣。每回合限一次，影響小。

6. **封封手上的共用忍術牌仍帶「忍術·」前綴**（可能，看設計意圖）
   - `src/content/cards.ts:1098-1102`：`cardNameFor` 只替菲菲、噹噹拿掉前綴，封封走 `def.name`；圖鑑分區 `src/ui/compendium.ts:34-36` 也照舊寫「忍術」。
   - 契約只說「牌池沿用忍術」，沒講牌名；噹噹當初是使用者明示要拿掉。封封是劍客，若也要拿掉，這兩處要一起改。

## 查過、沒有問題的項目（給主代理對照）

- **封封接線**：`HEROES`、`HERO_NAME`、`startRelicFor`、`SHARPEN_VERB`、`starterDeckFor`、`pickable`（封封起手不進獎勵）、`MIRROR_SKINS`、`deckLeaning` 的起手排除、`heroSpeaker`／`portraitHero`、選角、`motionSourceFor` 都有第四格。`deckLeaning` 對封封走「隱身」派，但封封的結局插句五派都是同一句，不會播錯。
- **蓄氣**：開場 2＋第一回合 1＝3（探針確認）；上限 12 由 `gainQi` 夾住；蓄滿時舊劍穗不閃。14 張花氣牌的 `perQi` 跟 09-22 註記一致，牌面文字數字與效果一致（32 張逐張印出比對過）。多段、群攻只付一次；影子分身重播重新取快照、重新支付，下一擊準備在重播時若沒提高就不扣氣（探針：你從右邊上＋影子分身，同伴拿到 12、封封剩 3 氣，重播沒再扣）。倒下、清場、戰鬥結束都歸零。
- **鏡中對手**：花氣傷害照牌面上限學成固定傷害（平斬 11、踏步重劈 23、穿堂劍 20 穿透…），用盡蓄氣兩張不學、支援與產氣牌整張不學，沒有例外路徑。
- **師父換血條**：乘的是 `cs.mods.hpMul`，已含遭遇倍率、難度與連線（含 `COOP_HP_BY_ENCOUNTER` 的 2.4），沒有重複乘。探針：雙人第二條 576＝240×2.4。召喚與伏兵也都從同一個 `cs.mods.hpMul` 算。附帶提醒：這個修正同時讓**單人難度 3 以上**的師父後兩條血也 ×1.15（240→276、300→345），註解有寫「連線、難度」所以應是有意，但 09-22 的量測只做難度 1。
- **鐵爪機關貓**：四招攻擊都帶 `pierce`；穿透跳過蜷縮、照吃隱身與反彈；蓄力不加倍穿透招，預告（`intentpreview.ts:35`）與實際一致；卡住只剩看破，減半算法 3→1、2→1、1→0 與名詞表一致。
- **噹噹卸蜷縮**、**銅牆鐵壁**（先給 8 蜷縮，再掛只卸一半）、**菲菲飛針**（打之前的毒快照決定給不給 1 點蜷縮）、**淬毒 3 層**：引擎與牌面一致。
- **非決定性**：`src/engine` 內沒有 `Math.random`、`Date.now`；`content/dialogue.ts` 的 `pick` 用 `Math.random` 但只給演出、引擎沒有引用。指紋（`net/hash.ts`）已納入蓄氣、下一擊準備、集中精神與能力細節。
