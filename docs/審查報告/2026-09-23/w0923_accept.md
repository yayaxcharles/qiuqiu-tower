## 六、沒測到的

- **真手機、真平板、iOS Safari**：全部是 Chrome 的觸控模擬。
- **有畫面的瀏覽器**：全程無頭（沒有 GPU 合成），閃白那 75 毫秒在有顯示卡的真瀏覽器上長短可能不同。
- **聲音**：無頭又靜音，貓叫、音效沒驗。
- 事件裡「要打一場」的戰鬥、紙箱（8F）這次地圖跳格跳過了；罐頭鋪只買了牌，沒買秘寶與忍具。

- 同角色雙人（兩隻都是球球）的連線沒測。
- 第三關、最終戰、結局沒走到（封封只走到第三關地圖）。
- 效能比的是新版打包檔 vs 舊版開發伺服器（派工單的規定），兩邊條件不完全一樣；結果本來就一樣，所以結論不受影響。
