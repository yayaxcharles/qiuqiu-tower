## ② 新增素材清單與體積

`tools/add_art26_bg.py` 跟 `add_screen_bg.py` 用同一個出口（`public/assets/bg/<鍵>.webp` 加 manifest），差別在四個地方：

1. **照牆腳位置裁，不置中裁**。牆腳是後牆跟地板交接的那條線。原稿是 1536×1024，縮到 1280 寬後，照量到的牆腳裁成 16:9，讓牆腳落在舞台 y=388。角色腳底固定在 403，等於站在地板前緣。所以新圖都照原尺寸鋪，不放大，也不用登記 `BG_ZOOM`。
2. **WebP 品質 85**（`recompress_webp.py` 的規矩）。舊背景是 66，所以新圖一張大約是舊圖的兩三倍大。
3. **manifest 照原格式寫回**（縮排 2）。`add_screen_bg.py` 用縮排 1 寫，會把整份 manifest 改格式、三條線合併時撞成一片，所以沒用它。

## ⑤ 沒做的、做不到的、拿不準的

1. **首載程式只剩 0.2 KB**（699.8／700.0 KB）。牌線、介面線如果也改到首載那幾支（`assets`、`main` 那兩塊），合併後幾乎一定超標。這條線沒去調高預算，那是使用者的決定。
2. **進戰鬥那一項 +7.5%**，在門檻內但不遠，而且是量最壞的情況：清空快取、慢網路、開局後直接跳到第 3 層。正常玩法每一關的第 1、2 層一定是舊背景（測試有釘住），新圖到該關第 3 層才輪到；第二、三關的新圖在過關畫面時就開始抓（排在那一關魔物後面）。正常順序（第 1 層開打）與第二關開頭沒有另外量。
3. **舊的九張背景沒有加動效**。設定格式支援（在 `BG_FX` 加一筆就好），但舊圖有 106～113% 的放大，燈位要換算成舞台座標，這次沒做。舊背景照舊只有原本的火光、暖光、浮塵。
4. **輪替方式變了**：一關內六張輪，用關內樓層取餘數，每一關第 1、2 層一定是舊圖（第一版用跨關累計樓層，第二關第 16、17 層會輪到新圖、而新圖又排在預載最後——審查時抓到、已改）。舊三張出現的頻率從每層變成每六層三次。牆、地板在相鄰樓層的變化比原本多。
5. **動效的強弱是看截圖調的，沒有真人看過動起來的樣子**。霧的濃度（每張 0.35～0.6）、光束最亮 0.07～0.12、燈 0.28～0.36，都可能需要使用者實際看過再調。膠卷只能看出有在動，看不出順不順眼。
6. **新背景的品質 85 比舊的 66 大兩三倍**。不算首載，但進第二、三關時過關畫面要多抓約 250 KB。
7. `npm run docs:dump` 也會重寫 `docs/事件文案.md`、`docs/怪物工作檯.json`、`docs/牌池總表.json` 三份。內容跟這條線無關，我還原了，沒提交；測試用倉庫裡那一版照樣全過。那三份為什麼重產會不一樣，沒有追。
8. 前景框景物（左右邊緣的柱子、上緣的樹枝、屋簷）在 low_1、low_3、mid_1、mid_3、top_3 的左邊緣，跟球球的尾巴有一點重疊。球球畫在它們前面，看起來沒問題，但嚴格說「站位那塊不要放東西」只做到「站位那塊沒有地上的物件」。

## 動效設定格式與每張背景開了哪幾項

格式在 `src/ui/ambient.ts`（`BgFx`、`BG_FX`），鍵是 manifest 的 `bg/...`，座標是舞台座標（1280×720）：

```ts
{
  floor?: number;   // 牆腳 y，呼吸縮放的中心線（預設 388）
  fog?: { y, h, a, rgb?, sec? } | false;             // 霧帶中心 y、高、最濃不透明度、顏色、飄一圈幾秒
  beams?: { x, y, w, len, tilt, rgb, a }[] | false;  // 光束頂端中心、頂寬、長、斜率、顏色、最亮不透明度
  lamps?: { x, y, r, rgb?, a? }[] | false;           // 燈中心、光暈半徑、顏色、最亮不透明度
  breathe?: boolean;                                 // 呼吸縮放
}
```

- 某一項不要，就在那張的設定裡拿掉或寫 `false`。沒有設定的背景（舊九張、三張關主戰場）一項都不畫，跟改版前完全一樣。
- **全域開關**：網址加 `?bgfx=0` 全關，加 `?bgfx=fog,lamps` 只開列出來的那幾項。量測時用 `PERF_QUERY` 傳進去。
- **怎麼守住效能**：
  - 只動 `transform` 和畫布上的透明度，不碰 `filter`、`box-shadow`、`background-position`，也不改尺寸。
  - 不另開畫布：只有原本那張環境光畫布，加一條離屏霧帶貼圖，每種顏色整頁只畫一次。
  - 浮塵粒子數沒有增加。
  - 呼吸縮放不另跑一條每秒 60 格的動畫，而是跟著畫布每秒 30 次的節奏改，數值沒變就不寫。
  - 每一格只畫當下這一張背景的設定，工作量跟背景總張數無關。
- **節奏**：光束透明度約 7.4 秒一輪；燈是三個不同頻率的正弦疊起來，不規則但連續；霧 65～95 秒飄一整圈；呼吸 20 秒一輪。時間都用頁面時鐘：出牌時戰鬥畫面會整個重建，動效接著原本的位置走，不會跳回起點。
