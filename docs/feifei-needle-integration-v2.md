# 菲菲九張針牌動作整合 v2

## 範圍與不變條件

本次只改畫面動作、投射物排程、試打配置與對應測試。牌費、傷害、命中段數、狀態效果與引擎結算皆未修改。

菲菲所有針招保持原地施放；只有既有爪擊與踢擊會貼近目標。其他角色既有近戰與防禦判定不受本次整合影響。

## 波次與中斷規則

- 整身動作只保留本次真實命中需要的離手預備段。連針一段時會略過第二次離手，兩段時完整播放，更多段則每 140 毫秒重播投針子段，最後仍播放收招。
- 命中計畫不會把段數裁到素材內建離手次數。影子分身造成四段或更多連針時，所有真實命中都會保留。
- 下一張牌可立即換掉菲菲的整身動作；已經離手的投射物由獨立排程持續飛行，不會被下一張牌取消。
- 全體針招的散針只增加視覺數量，不增加 `onImpact` 次數。每隻敵人的一筆真命中仍只回呼一次。
- 所有針招都可用狀態差建立只有狀態效果的命中計畫。一針斃命條件失敗且沒有生命、死亡或減益變化時，回傳空計畫，不顯示假命中。
- 不要過來！即使同時取得蜷縮，也先由卡牌映射取得 `needle_retreat`。若自傷使菲菲倒下，戰鬥反應判定會先處理倒下，不會強播防禦動作。

## 多段整身與戰鬥握手

- 球球 `palm_combo`、噹噹 `rapid_combo`／`sweep_combo` 與封封 `sword_combo` 都依真實一、二、三段裁切整身攻擊；接觸點分別保留到 220、460、700 毫秒，攻擊本體長度為 520、760、1000 毫秒。
- 封封三拍連刀裁切後再接完整 510 毫秒收劍，因此總長為 1030、1270、1510 毫秒。
- 戰鬥確認結果會同時更新逐格演員、近戰停留行程與結束時間。三段攻擊在 700 毫秒仍停在敵前，1000 毫秒收完才回原位。
- 全體攻擊以所有目標命中計畫的最大段數控制本體。即使最後一隻敵人只承受一段或提早倒下，也不會把其他敵人的二、三段整身動作截掉。
- 新攻擊的短效只在已確認的正傷害命中時觸發；零傷、格擋或閃避不會產生假劍光、衝擊環或地裂。

噹噹的共通牌必須以 `cardNameFor(def, 'dangdang')` 的顯示名判斷。`luanwu` 在他手上是「橫掃千軍」，原始卡圖雖仍畫了手裏劍，程式註解與玩家看到的牌名都已明定為掃堂腿，因此不能把它接成投擲。

|---|---|---|---|
| `rapid_combo` | `dangdang_fanshou` 反手一記、`roubao` 肉球連擊、`shierlian` 絕學·十二連環 | 前兩張 2 段，反手一記升級與十二連環 3 段 | 牌名與角色卡圖都是近身拳掌連打；整身只播放實際二或三擊 |
