# 角色二・阿甲　劇情與台詞（2026-09-03 完整草稿，等使用者審）

規則：阿甲講話慢，句尾不加「喵」（正式接入時測試另立一條：阿甲台詞不可出現「喵」）；常用「……」；把球球叫「球球」；師父的稱呼暫用「大俠叔」（待定，也可以叫「師父」）。旁白不加語尾。名字「阿甲」是佔位，之後全文替換。

## 八、結局與失敗

- 勝利（幻燈片沿用球球結局的畫面）：「……大俠叔，醒了嗎？球球，我來了。」／旁白：塔頂的風停了。一隻慢慢的烏龜，走到了最快的那隻貓旁邊。／「回村的路上，球球跑在前面，我在後面慢慢走。這樣剛好。」
- 失敗：「殼……裂了。球球，你要撐住……」／結算畫面：「我先……躺一下。」

## 九、待使用者決定

1. 名字（阿甲／甲羅／其他）與外型（顏色、頭巾顏色、有沒有背包或斗笠）——定了才生設定表，其餘立繪、序章、牌面都用設定表當參照。
2. 對師父的稱呼：「大俠叔」還是「師父」。
3. 語尾要不要一個固定的口頭禪（現在是「……」和「慢慢來」）。
