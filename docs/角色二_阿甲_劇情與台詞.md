# 角色二・阿甲　劇情與台詞（使用者修訂版，2026-09-03 定稿）

規則：阿甲講話慢，句尾不加「喵」；常用「……」；把球球叫「球球」，師父叫「大俠叔」。旁白不加語尾。名字「阿甲」是佔位，外型與名字待定。
初見、關主、換階段、打贏、貓窩商店事件、過關都有多句：正式接入時做成隨機池（每隻／每處一個陣列，第一句當保底）。

## 十一、名字與外型（提案，2026-09-03）

**名字**（三選一，建議第一個）：
1. **阿甲**——樸實憨厚，跟「球球」一個圓一個方，唸起來像村裡叫慣的小名；台詞已全部用這個名字。
2. **甲羅**——日文「龜殼」的讀法，跟塔裡妖怪的日式世界觀對得上；缺點是中文玩家看不出意思。
3. **龜吉**——老派日式「～吉」，有慢性子老實人的味道，跟「大俠叔」這種叫法很搭。

**外型**（三選一，建議 A，可以把 B 的斗笠掛在背後合併）：
- **A 龜甲流弟子**：橄欖綠皮膚、深褐色六角紋圓殼、**紅色頭巾**兩條尾巴（跟球球的藍頭巾成對比、一眼認得出是「另一個主角」）、短褐背心、背一個小布包袱（序章打包的那個）；眼睛圓但眼皮微垂（慢性子）；比例跟球球一樣頭大身體小，身體比球球寬一圈。
- **B 斗笠旅人**：A 的基礎上加一頂斗笠（序章第一張拿在手上，戰鬥時掛背後）、腳綁綁腿、殼上刻一個龜甲流的紋章。
- **C 小龜忍者**：藍黑忍裝跟球球同門——不建議，劇情說牠練的是龜甲流不是忍術，也會跟球球撞色。

**朝向**：立繪一律朝右（球球那邊翻過兩張的教訓）；設定表要三視圖（正面、朝右側面、臉部特寫）。
