# 角色二・烏龜「姆斯」設計稿（2026-09-03，先定牌組）

使用者拍板：第二隻角色走「防禦當攻擊」的烏龜；劇情＝來幫球球的朋友。先把牌組設好，工程之後再排。

## 一、角色與劇情

- **名字**：姆斯（2026-09-03 定案）。忍者村裡跟球球一起長大的烏龜，動作慢、脾氣好，練的是「龜甲流」——不躲不閃，硬接下來再用殼撞回去。
- **劇情鉤子**：球球一個人上塔去救師父，村裡沒人攔得住牠；姆斯收拾了包袱慢慢跟上來，「球球跑太快了，我來保護牠，替牠把師父帶回來。」序章第二版：同一段故事從姆斯的角度講（三張幻燈片：村口目送球球→夜裡收拾包袱→站在塔下抬頭）。過關與結局台詞各寫一組，師父戰的對白換成「師父，球球在前面等你，我要帶你回去找球球」。
- **語尾**：球球是「喵」，姆斯不用語尾詞，講話慢、常用「……」（測試要另設規則：姆斯台詞不可有「喵」）。
- **數字**：起始血 84（比球球多 8，換來的是沒有隱身）；起始小魚乾 50；起始秘寶「老龜甲」。

## 二、核心機制（蜷縮就是牠的武器）

| 名詞 | 規則 | 引擎現況 |
|---|---|---|
| **撞擊** | 造成等同你目前蜷縮的傷害，蜷縮不減 | 已有 `damageEqualBlock`（借刀） |
| **留殼** | 回合開始時蜷縮不歸零（保留全部或 N 點） | 秘寶有 `blockKeep`（回合末裁到 N）；能力牌版本要新增 `keepBlock` 效果 |
| **殼刺** | 反彈：被打中就回敬 | 已有狀態「反彈」 |
| **縮頭** | 這回合完全不受傷 | 已有 `immuneThisTurn`（縮頭功） |
| **甲裂** | 把蜷縮全部換成傷害（打完歸零） | 新增 `blockToDamage`（乘數 1 或 1.5） |
| **厚殼** | 每回合開始獲得 N 蜷縮（能力） | 已有 `power` 觸發 `turnStart`＋`block` |
| **重心** | 蜷縮越多攻擊越痛：攻擊傷害 +蜷縮／5 | 新增 `damagePlusBlockRatio` |

沒有隱身、沒有潛水：姆斯不閃，全靠蜷縮與回血。爪力照舊可堆但牌少。

## 五、需要新增的引擎效果

1. `blockToDamage: { mult }`——傷害＝目前蜷縮×mult，打完蜷縮歸零。
2. `keepBlock: { amount | 'all' }`——能力：回合開始不歸零（跟秘寶 `blockKeep` 合併成同一條路：取最大值）。
3. `damagePlusBlockRatio: { div }`——能力：攻擊傷害加 蜷縮÷div。
4. `blockDouble: { cap }`——回合結束蜷縮加倍到上限。
5. `blockToHeal: { cap }`——蜷縮換回血。
6. `onBlockGainDamage: { amount }`——本回合每張獲得蜷縮的牌打 N 點（`power thisTurn`）。
7. 角色系統：`RunState.hero: 'qiuqiu' | 'ajia'`；起手牌組、起始秘寶、立繪、台詞（序章／過關／結局／師父戰）、狀態列名字、機器人的估值（蜷縮要算成攻擊資源）。
