## 2. 程式怎麼改（白話）

**一階倒下（`late`，晚一點才下載的基本動作）**
- 放在 `side-motion/<套>.json` 的 `late.knockdown`，**不算進「這隻準備好了沒」**：第一階段的出招不會因為多一張 0.5～1.5 MB 的倒下圖集而晚到。
- **圖集真的到了才算有倒下**（`enemyMotionHas`）。倒下那一刻的所有判斷（長倒下、交還立繪、小怪化煙、等爆炸演完才換場）都走這一支，所以圖還沒到時**一致**退回原本的靜態倒地圖淡出，不會一邊說有、一邊畫不出來（空白魔王）。
- 引擎在致命一擊時**不換階段**（`checkPhase` 看到已倒下就不動），所以一刀從第一階段打死，畫布就是第一階段那一套，會播這段。
- 畫布大小把 `late` 一起算進去，播倒下時畫布、腳底不跳。

**下載順序**（`combat.ts` 開打那一段，全部不插隊）：
1. 這一階段的基本圖集
2. 第二階段的出招與爆炸
3. 這一階段的招式片段與變身
4. **這一階段的倒下（新）**：一刀從第一階段打死很少見，所以排在常看到的招式片段後面；第一階段還在打就要到，所以排在第二階段招式片段前面。**排到這裡時已經打到第二階段了就不抓**（0.8 Mbps 實測換階段後還在抓 1.5 MB 的鐵爪一階倒下，修掉了）
5. **這一場的特效圖集（新）**
6. 第二階段的招式片段（含橘皮大王的龍捲滾、蓄力）

一般魔物（燈籠妖）：就緒之後排招式片段，再排特效。

**特效圖層**（`src/ui/fx-layer.ts`）
- 每一次放特效是一張小畫布，掛在宿主（魔物或被打的那一位）的立繪框裡，中心點放在「腳底往上 y、往右 x」（以立繪框高為 1）。
- **前面那層** z-index 1、排在框的最後（主角、魔物的逐格畫布也是 1，重掛時會被排到後面，實測燈籠妖的爆炸一開始整團被主角擋掉，已修：每一拍檢查、排回最後）。**後面那層** z-index 0、插在地上影子後面、立繪前面。名字、血條、牌子是 2，意圖牌 6，所以特效永遠在它們底下；`pointer-events: none`，不擋點擊。
- 框被重畫換掉（挨打、整頁重畫）就搬到新框，播到一半不中斷；那一格不見了就收掉。
- 圖集沒到就這一次不放（不等、不卡、不插隊）。
- 換場時全部停、不拔（舊畫面墊在底下淡出那 220 毫秒還看得到，跟逐格畫布同一規矩）。
- 打在誰身上看**引擎狀態**（這一拍血或蜷縮少了的那一位），不看畫面，連線兩台一定打在同一位；閃過（血與蜷縮都沒少）就不放。
- 倒下的提示只有逐格倒下**真的在演**才放（時間照倒下片段的關鍵格）；退回靜態倒下的不放那一套的提示。

**打包**
- `tools/pack_side_motion.py`：新增 `death(..., segments=, late=, new=, marks=)` 與 `move(..., new=)`。`new=True` 讀素材盤點資料夾的 `anims_new.json`（不併進 qiuqiu-side）。每段動作的關鍵格（`hit`、`spark`、`fall`⋯⋯）換算成「開演後幾毫秒」寫進 json 的 `marks`，特效照它對時間。報告檔多記每段挑了哪些來源格（`src_frames`），測試靠它檢查白光格有沒有被剪掉。
- 舊的 71 張圖集一個位元組都沒變；舊的 21 套 json 只多了 `marks` 一欄。
- `tools/pack_fx.py`：三支特效原尺寸打包（不縮），只裁每格四周透明邊、每 2 格取 1（跟魔物片段同節奏），頭尾幾乎全空的格子不收。

## 5. 特效圖層資料格式（師父那條線照這個接）

### 5.1 特效圖集：`tools/pack_fx.py` → `src/ui/fx/sprites/<名>.json`＋`public/assets/motion/fx/<名>.webp`

新增一支特效：素材放成 `<來源>/fx/<名>/NN.webp`＋`anim.json`（`anchor`＝特效中心在圖裡的位置，每格同一張大小），在 `pack_fx.py` 的 `FX` 加一行 `"<名>": {"first": 第幾格, "last": 第幾格}`，跑 `python tools/pack_fx.py --only <名>`。產出的 json：

```json
{ "texture": "assets/motion/fx/<名>.webp", "scale": 1, "size": [寬, 高],
  "frames": [ { "rect": [x, y, w, h], "pivot": [中心點x, 中心點y], "duration": 0.0833 } ] }
```

### 5.2 提示表：`src/ui/fx/cues.json`

```json
{ "cues": [
  { "owner": "iron_claw", "on": "death", "fx": "blast_large", "at": "spark",
    "x": -0.04, "y": 0.4, "scale": 1.15, "speed": 1.2, "layer": "back" }
] }
```

| 欄位 | 意思 |
|---|---|
| `owner` | 誰的。逐格動作那一套（`iron_claw_p2`），或 **`enemy:<魔物編號>`**（每個階段都算）、**`enemy:<魔物編號>@<階段>`**（階段 0 起算）。師父沒有逐格動作，用 `enemy:tower_master@0`、`@1`、`@2` |
| `on` | 什麼時候：`death`（倒下）、`change`（換階段那一刻，算新階段的）、`attack`（出任何攻擊招）、`move:<招式名>`（出這一招，招式名是 `enemies.ts` 的原文）、`aura`（站著時一直有，自動循環） |
| `fx` | 哪一支特效（5.1 的名字） |
| `at` | 開演後幾毫秒；寫字串＝那一段逐格動作的關鍵格（`hit`、`spark`、`fall`），查表在 `side-motion/<套>.json` 的 `marks`。沒有逐格動作的（師父）寫數字 |
| `host` | `self`（這隻，預設）或 `target`（這一拍血或蜷縮少了的那幾位；閃過不放） |
| `x`、`y` | 中心點位置，**以宿主立繪框的高為 1**：x 往右為正、y 從腳底往上。同一條提示放在大小不同的魔物身上也會跟著比例走 |
| `scale` | 特效原尺寸的幾倍（1＝來源 1 像素畫成戰場 1 像素） |
| `speed` | 播放速度（1＝每秒 12 格） |
| `layer` | `front`（身體前面，預設）／`back`（身體後面） |
| `loop` | 循環到被停掉（`aura` 一定循環） |
| `flip` | 左右翻 |
| `fadeOutMs` | 停下時淡出幾毫秒（循環的停下、氣場換階段或倒下時收掉） |
| `_why` | 註解，程式不讀 |

### 5.3 程式在哪幾個地方叫（`src/ui/screens/combat.ts`）

- 倒下：`fireDeathFx`（`fall()` 裡，`finishEnemyMotion` 之後）。逐格倒下真的在演才放逐格套的提示；`enemy:` 開頭的提示照放。
- 出招：`fireMoveFx`（逐隻演出的那一拍，換階段判斷旁邊）。
- 換階段：`phaseBurst` 旁邊（`on: "change"`，owner 用新階段）。
- 氣場：每次重畫那一格敵人時 `fxLayer.syncAura(...)`。該有的補上一次（循環照跑、框換了自己搬），換階段或倒下（表上沒有了）就照 `fadeOutMs` 淡出收掉。
- 下載：開打時照第 2 節的順序排 `prefetchFx(fxNamesFor(這一場的 owner))`；**沒有逐格動作的魔物（師父）目前沒有排**——師父那條線加提示時，在開打那段把 `fxNamesFor(fxOwnersOf('tower_master', 階段))` 也排進去（建議排在主角動作之後、不插隊）。

### 5.4 師父那四件事怎麼寫（範例，還沒放進表裡）

```json
{ "owner": "enemy:tower_master@0", "on": "aura",   "fx": "<黑氣>", "y": 0.45, "scale": 1.2, "layer": "back", "fadeOutMs": 400 },
{ "owner": "enemy:tower_master@1", "on": "change", "fx": "<黑氣爆發>", "at": 0, "y": 0.5, "scale": 1.4 },
{ "owner": "enemy:tower_master@2", "on": "aura",   "fx": "<閉關氣場>", "y": 0.3, "layer": "back", "fadeOutMs": 400 },
{ "owner": "enemy:tower_master",   "on": "death",  "fx": "smoke", "at": 200, "y": 0.4, "scale": 1.3, "speed": 1.2 }
```

「閉關」如果不是用階段分（是狀態），要在 `syncAura` 那一行多傳一個條件，現在只認階段與倒下。
