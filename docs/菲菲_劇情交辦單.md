## 0. 三十秒了解這個角色

《爪破魔塔：球球參上》是一款繁體中文的網頁牌組肉鴿遊戲。原本只有一個主角
**球球**（灰虎斑小貓忍者），2026-09-12 加了第三個可玩角色 **菲菲**。

- 菲菲是**暹羅貓**，球球的**師妹**，大俠貓（師父）的女徒弟，比球球晚三年入門。
- 故事：魔塔冒出來那晚，師父中了魔氣衝進塔頂，球球追了上去。**三天過去，兩個都沒回來**，
  於是她自己出發。她要接回來的是**兩個人**——這是她跟球球最大的差別
  （球球找的只有師父）。
- 打法：**下毒 ＋ 丟飛針 ＋ 攻擊的同時就擋好**。她怕痛、不近身、不硬碰。

### 她的說話規矩（最重要，全部都要遵守）

| 規矩 | 說明 |
|---|---|
| **句尾不加「喵」** | 那是球球的招牌。她一次都不能用。 |
| **「那個……」開頭** | 她的口頭禪，開口前先遲疑。不用每句都有，大約三到四句一次。 |
| **「我有先提醒你喔」** | 她的招牌句。對手中毒倒下時會小聲補這句。 |
| **先道歉、先警告、先退開** | 她不會說「衝上去」「打倒你」。她說「拜託站遠一點」「不要追我」。 |
| **稱呼** | 師父＝師父；球球＝**師兄**；自稱＝我（不自稱名字）。 |
| **不寫成勝利宣言** | 她從頭到尾沒有變勇敢，只是把事情做完了。 |
| **繁體中文、台灣白話** | 唸出來要像台灣人講的一句話。不要大陸用語、不要文謅謅。 |

## 1. 任務一（優先）：**把她現有的口頭禪重看一遍**

她每場戰鬥都會冒出這幾組短句，是玩家聽最多次的。我寫的第一版，**請你逐句挑錯與重寫**。

判準：
1. 有沒有句尾的「喵」（有就是錯）
2. 唸出來像不像台灣人講的話（不像就重寫）
3. 有沒有哪句聽起來太勇敢、太主動（那不是她）
4. 同一組裡有沒有兩句太像（重複的要換掉）
5. **長度**：每句最多 18 個字，短句更好——這些會跳在畫面上一兩秒

### battleStart（開打時，8 句）
1. 那個……先別過來。
2. 我先丟一根試試。
3. 不要追我喔，我跑得很快的。
4. 一層就好……不對，還是多疊幾層好了。
5. 針還夠，藥也還夠。
6. 拜託站遠一點。
7. 我不跟你比力氣。
8. 師兄的話現在一定已經衝進怪堆裡了。

### battleWin（打贏時，10 句）
1. ……倒了？真的倒了？
2. 我有先提醒你喔。
3. 毒有生效，太好了。
4. 呼……還好不用補第二輪。
5. 手、手還在抖。
6. 你如果不要追我，就不會變這樣了。
7. 這樣算我贏吧？
8. 我要坐一下……腿軟了。
9. 師父，我沒有硬碰喔。
10. 好餓……下毒也很累的。

### hungry（血量見底時，3 句）
1. 沒力氣了……針會丟歪。
2. 飯糰……沒有了。
3. 肚子好餓，連藥味都聞起來像湯。

### lowHp（快死了，3 句）
1. 不要過來——我真的會痛！
2. 我我我真的要回家了……
3. 等一下！毒還沒發作，你先站遠一點！

### chestLines（開紙箱，5 句）
1. 箱子……裡面該不會有東西吧。
2. 我先用針戳一下，不算弄壞吧？
3. 有人在裡面的話先說一聲，我的針有毒。
4. 站遠一點再開好了。
5. 希望是繃帶……或解毒藥。等等，解毒藥好像是給別人用的。

### restNapLines（在貓窩睡覺，4 句）
1. 睡一下下就好……一下下。
2. 這裡應該沒有東西會突然撲過來吧。
3. 先把毒針收好，睡著壓到會很糟。
4. 眼睛好澀……今天丟太多針了。

### restSharpenLines（在貓窩磨針，4 句）
1. 磨利一點，扎得淺也能把藥送進去。
2. 我力氣小，所以針一定要準。
3. 再上一層藥……薄薄的就好。
4. 師父說過，會準備的人，不需要逞強。

**交回格式**：每一組給我**同樣數量**的句子（8／10／3／3／5／4／4），
維持原本的編號。沒問題的直接抄回來，改過的在句子後面加 `　← 改了：<一句話理由>`。

## 3. 任務三：**再設計兩個她的專屬事件**

她現在只有兩個專屬事件（別的角色玩不到）：

1. **師兄的痕跡**：走廊上散著幾根被踩彎的針、一截頭巾線頭——都是球球留下的。
   選項 A 收拾好（拿回一點資源）／選項 B 沿著線頭追過去（撞翻東西、擦破皮，盡頭是他丟下的一卷東西）。
2. **調藥**：她蹲下來替針補毒。選項 A 薄薄上一層（安全）／選項 B 試毒（自己扣血，但換到更強的毒）。

請**再設計兩個**，規格：

- **必須是「只有她會遇到」的事**：跟毒、針、怕痛、找師兄有關，換成球球就不成立。
- 每個事件要有：**標題**（4～8 字）、**情境敘述**（2～3 句，第三人稱）、
  **2～3 個選項**（每個選項要有：選項文字、結果敘述 2～3 句、其中至少一句是她講的話）。
- 選項之間要有**真的取捨**，不能有一個明顯最好的。
  已經有的取捨長這樣：安全但少拿 ↔ 有代價但拿得多。
- **不要寫具體數值**（扣幾點血、拿幾個小魚乾）——那是我這邊平衡時決定的，
  你只要寫「代價比較大」「拿得比較多」這種相對描述。

請挑出「換得不夠好」的，重寫那幾句。特別注意：
- 有沒有哪句其實還是球球的語氣（太衝、太自信）
- 有沒有哪句把「師兄」漏掉了（她是來接兩個人的）
- 有沒有哪句唸起來不順

不用全部重寫，**只挑你覺得有問題的**，其他的寫「維持」。
