# 怪物與關主擴充・第二波（2026-09-02 晚定稿）

使用者的話：「怪物種類還是太少」「關主也太少」「參考殺戮尖塔的怪物特性，設定機制後生圖」。
這一波：**10 種新機制、12 隻新怪、4 個新關主、2 種召喚小怪、2 張塞進牌堆的雜牌**。
原則不變：**隱藏機制一律掛牌可見**（狀態牌子或單位下方的小牌，滑過去有名詞說明）、既有怪物與數字一律不動、同種子可重現（只用 `cs.rng`）。

---

## 一、新機制（引擎）

狀態類（加進 `StatusName`，只會出現在魔物身上；`decayTurnStatuses` 的通用衰減**不吃**這幾個，各自照下面的規則走）：

| 狀態 | 規則 | 名詞說明（glossary） |
|---|---|---|
| **縮殼 N** | 這隻**第一次**被攻擊扣到血時，立刻獲得 N 點蜷縮，狀態消失（一場只一次） | 第一次被打痛就縮回殼裡，馬上長出 N 點蜷縮 |
| **飛行 N** | 身上有飛行時，**攻擊牌**對牠的傷害減半（先減半再扣蜷縮）；每一段扣到血的攻擊 −1 層；歸零＝被打落，這回合內沒有飛行；牠的下一個回合開始時回到 N | 在天上飛，攻擊只打得到一半；連續打中 N 下就掉下來 |
| **鱗甲 N** | 牠的回合結束時獲得 N 點蜷縮；每一段扣到血的攻擊 −1 層（最少 0） | 每回合結束長出等同層數的蜷縮；每被打痛一下就剝落一層 |
| **沉睡 N** | 有沉睡時牠什麼都不做（意圖顯示「呼呼大睡」）；每個牠的回合 −1；**任何**扣血立刻叫醒（狀態歸零）並觸發 `onWake`（定義在 EnemyDef，通常是自己 +爪力） | 睡著了不會動；打痛牠會醒，醒來會很生氣 |
| **消散 N** | 每個牠的回合結束 −1；歸零時牠散去（走 `escape` 的路：不掉戰利品、不算打倒），紀錄「〇〇散去了」 | N 回合後自己消失；想拿獎勵就得在那之前打倒 |

被動類（`EnemyDef` 新欄位，畫面上在單位下方掛一張小牌，跟「僕從護體」同一套）：

| 欄位 | 規則 | 小牌文字 |
|---|---|---|
| `splitInto: { enemyId; n; below }` | 血量 ≤ 最大值 × below（0.5）時，牠本體消失（不算打倒），原地冒出 n 隻 `enemyId`，每隻血量＝牠剩下的血；一場只一次；召出來的照「敵方回合召喚」規則（快照保證當回合不動） | 分裂（半血） |
| `hexOnSkill: { cardId; n }` | 玩家每打出一張**技能**牌，就把 n 張 `cardId` 塞進玩家的**抽牌堆**（洗進隨機位置） | 詛咒：打技能就塞牌 |
| `angerOnSkill: number` | 玩家每打出一張技能牌，牠 +N 爪力，紀錄「〇〇被激怒了」 | 憤怒：打技能就變強 |
| `onWake: EnemyEffect[]` | 配合沉睡用 | （沉睡的說明裡講） |
| `flying: number` | 開戰帶飛行 N，每回合開始補回 N | （用狀態牌子） |
| `plating: number` | 開戰帶鱗甲 N | （用狀態牌子） |
| `curlUp: number` | 開戰帶縮殼 N | （用狀態牌子） |
| `asleep: number` | 開戰帶沉睡 N | （用狀態牌子） |
| `fadeAfter: number` | 開戰帶消散 N | （用狀態牌子） |

出招類（`EnemyEffect` 新種類；`describeMove` 與意圖圖示都要接，`actions.ts` 的 `default: never` 會逼你接齊）：

| 效果 | 規則 | 意圖 |
|---|---|---|
| `{ kind: 'selfDestruct'; amount }` | 對玩家造成 amount 傷害（吃蜷縮、隱身照閃），然後牠自己死掉（算打倒、掉戰利品） | intent `attack`，標籤自帶「爆」字，提示「自爆：造成 N 點傷害，然後牠自己也倒下」 |
| `{ kind: 'statusAllies'; name; amount }` | 場上所有活著的魔物（含自己）獲得狀態 | intent `buff`（既有的 buff 圖示），提示「全體獲得 N 點爪力」 |
| `{ kind: 'blockAllies'; amount }` | 場上所有活著的魔物（含自己）獲得蜷縮 | intent `block`，提示「全體獲得 N 點蜷縮」 |
| `{ kind: 'giveCard'; cardId; n; to: 'discard' \| 'draw' }` | 把 n 張雜牌塞進玩家的棄牌堆或抽牌堆（抽牌堆＝洗到隨機位置） | intent `debuff`，提示「把 N 張〇〇塞進你的棄牌堆」 |

雜牌（`cards.ts`，pool 仍是 `壞毛病`，但加欄位 `combatOnly: true`：不會出現在事件／獎勵／圖鑑的壞毛病清單裡，戰鬥結束就消失——戰鬥本來就用牌組的副本，所以自然消失，只要獎勵／圖鑑濾掉即可）：

| 牌 | 費 | 規則 | 牌面 |
|---|---|---|---|
| **黏液** `slime_card` | 1 | 打出＝消耗（什麼都不做，只是花 1 顆飯糰把它丟掉） | 黏答答的。花 1 顆飯糰把它甩掉。消耗。 |
| **眼冒金星** `dazed_card` | 0 | 不可打出；**虛幻**：回合結束留在手上就直接消失（不進棄牌堆） | 眼前一片星星。不可打出，回合結束就消失。 |

「虛幻」是新的 `Keyword`（`'消耗' \| '保留' \| '不可打出' \| '虛幻'`），`cardtext.ts` 的關鍵字說明與 glossary 都要補。

## 四、驗收

1. `npx vitest run` 全綠；`tests/content/enemies.test.ts` 的數量改成：一般（弱＋中＋強）46→58、大魔物 5、塔主 7→11、召喚 8→10。
2. 每個新機制至少一個引擎測試（縮殼只觸發一次、飛行減半與打落、鱗甲回合末補蜷縮與剝落、沉睡不動與被打醒、消散到期散去且不算打倒、分裂血量與只一次、詛咒塞牌、憤怒加爪力、自爆殺自己、鼓舞全體、塞牌進兩種牌堆、黏液可花費消耗、眼冒金星回合末消失）。
3. `describeMove` 每個新效果都有提示文字；狀態牌子與被動小牌在戰鬥畫面看得到；glossary 有名詞說明（`tests/content/glossary.test.ts` 若有覆蓋檢查要過）。
4. 機器人（`src/engine/smartbot.ts`）對新效果不能丟例外；`SMART_N=100 SMART_DIFF=1 npx vitest run --reporter=verbose tests/smart.report.test.ts` 跑得完並印出新怪的敗場統計。
5. 立繪未生成前一律灰剪影（既有退路），不得因此報錯。

生圖工作檔另見 `tools/make_wave2_monster_jobs.py`（本波 18 個單位的立繪描述）。
