# 連線版動作與操作回歸稽核

日期：2026-09-20。範圍為新版動作啟用後的受擊、閃避、出牌、音效、載入、離場清理與連線回合交接。保留既有卡牌數值與遊戲規則。

## 已確認並修正

1. 球球受擊的明顯後仰表情只有約 150 毫秒，後半段已回到站姿。延長後仰影格，整段受擊為 650 毫秒；其他角色反應亦保留至少 650 毫秒。每次新命中重新播放反應。
2. 球球消耗隱身時要求不存在的 `dodge` 動作，實際落回待機。改用既有 `roll`，並依剩餘隱身層數保留透明度。
3. 每次動作收尾重建整個戰場，重建手牌並提早移除傷害數字及受傷提示。改成原地收姿勢及同步靜態備援圖；新版角色畫布補回受擊紅閃。
4. 第一次使用未載入音效時只開始下載，沒有播放本次音效。現在共用下載與解碼後播放，紙箱使用的秘寶音效提前載入；靜音、逾時與失敗重試均有檢查。
5. 敵人與角色每個螢幕更新都重新計算影格時間、重畫相同影格。快取固定時間資料，只有影格或呼吸變化才重畫，保留原動作時間與腳底位置。
6. 首頁等待整批動作圖集而無法先顯示標題。改成先顯示標題，再於背景預載。
7. 試玩切換角色期間離開畫面，稍後載入完成仍會重設試玩。加入畫面版本檢查，離場後不再執行晚到的續接。
8. 客端排演批次時延後暫停會話，使新回合動作先套入舊回合。最後舉手確認時立即對帳與暫停，待該批演完才收回合；雙端回合追上後狀態一致。

## 驗證

- `npm test`：234 個檔案通過、4 個略過；1837 項測試通過、5 項略過。
- `npm run build`：型別檢查與正式打包通過。
- 新增及補強受擊實際影格、四角色反應時長、連續命中、隱身透明度、原地收尾、首次音效、相同影格重畫、非同步離場、首頁先顯示與批次交接測試。
- 瀏覽器獨立試打：兩張貓抓依序結算，敵人 9999 → 9993 → 9987；兩次敵方攻擊後球球 52 → 44。另局獲得一層隱身後，兩次攻擊只扣 4 點生命，留下「球球閃過了」紀錄；跑步換場可啟動。檢查期間瀏覽器無警告或錯誤紀錄。
- 效能測試在相同模擬時間下，敵人待機繪製由每秒 62 次降為 1 次；老鼠攻擊由 52 次降為 8 次；忍者攻擊由 46 次降為 4 次，抽樣影格相同。這是繪圖呼叫量，並非使用者裝置的實測每秒畫面數。

瀏覽器驗證使用不保存進度的試玩頁；未覆寫使用者正式存檔。聲音播放以音訊節點及解碼流程測試驗證，未以實際聽音宣稱所有裝置音效正常。部署後仍須核對雲端發布與線上主程式，僅完成提交不等於已上線。
