## 完整繪圖提示

每張圖片的完整提示為以下「共用段」加上對應的「動作段」。

### 共用段

```text
以兩張參考圖中的「噹噹」為唯一角色造型依據，延伸繪製新的單一戰鬥動作。第一張是已定案外型與動作風格，第二張是正面與側面比例依據。必須是完全同一隻黑白護衛貓，不能重新設計角色或服裝。

輸出一張正方形、完整全身、單一角色的高品質二維遊戲動作插畫；不是拼貼、不是多格設定圖。角色主要朝畫面右方，取能看清臉與動作的前側四分之三視角。耳朵、腳掌、尾巴、拳頭全部入鏡，動作最大範圍外保留至少 8% 空白。純淺暖米白背景，只有腳底簡單淡影，不要背景場景、文字、圖示、框線、敵人或另一隻貓。

完全保留：原圖黑白毛色、黑色圓頭與兩隻短三角耳、粉紅耳內、窄白色額鼻花紋與寬白口鼻、琥珀金眼睛、粉紅鼻子、白色貓手腳、原圖敦實但靈活的身材。衣服是灰青綠無袖短褂、米白滾邊、兩個深棕盤扣、深棕布腰帶及垂帶、深灰寬褲、深色腳踝綁布。一根粗黑圓尾自然連在骨盆後面。

兩個相同大小的古銅圓弧護臂，外形和參考圖完全一致：溫暖古銅凸面、雙道圓邊與少量刮痕、深棕皮革扣帶固定於前臂外側，白色貓爪伸出護臂末端，護臂是穿戴裝備，不能變成手拿盾牌、巨大拳套或球。每一隻手都有可理解的肩膀、上臂、肘、前臂、手腕連接；遠侧手臂也要有明確用途，不可無故懸在後面。兩隻貓爪大小一致，透視只做合理縮放。每個人物恰好兩隻手、兩條腿、一根尾巴。

畫風沿用參考圖：乾淨深色粗輪廓、圓潤可愛、有力的武俠姿勢、清楚的剪影、少量柔和賽璐璐陰影。材質簡潔，護臂保留少量金屬光澤；不能變成照片、寫實毛髮、立體公仔或不同畫風。動作幅度要大，重量傳遞要合理，身體隨肩胯動作轉動；避免只有手掌小幅挪動。

```

### 01_攻擊：動作段

```text
本張動作：向畫面右方踏步打出一記有分量的護臂直拳。前腳大幅踏出並屈膝，後腳有力蹬地，腰部和肩膀向前旋轉；出拳的手臂伸出身體輪廓外約一個頭寬，肘部自然接近伸直而不反折，拳頭高度在胸口至肩膀之間。護臂與白色拳頭必須連續可讀，不能把拳頭變成銅色。另一隻手自然彎肘收在胸前保護下巴，保持大小一致。眼神專注、嘴巴微張吐氣。腰帶和尾巴因動作向後甩。僅用兩三條短而俐落的淡青風線表現拳勢，不要巨大能量波，不要把動作埋在特效裡。重點是強烈的跨步、扭腰、肩膀送出與完整伸拳。
```

### 02_格擋：動作段

```text
本張動作：穩穩架起兩個銅護臂，準備擋住從畫面右方來的正面重擊。寬低站姿，雙膝彎曲，前腳朝右而後腳斜後支撐，整個重心沉下、身體略向前迎力。兩隻前臂在胸口前方朝上斜立，前後錯開一點點，銅護臂的外側迎著右方攻擊；兩隻手各自握拳、都在下巴以下，手肘在肋骨附近自然彎曲。姿勢像實用的雙臂高位拳擊防守，護住胸口到下巴；不要把胳膊扭成不可能的交叉結，不要手掌蓋住臉。需要看得懂近側肩肘腕與遠側肩肘腕各自的連接，也要看見兩個銅護臂與兩隻白爪。臉從護臂上方清楚露出，眼神堅定看右方。服裝、尾巴靜穩，沒有攻擊特效、光牆、能量盾或魔法罩。這張必須一眼是有重量的格擋，而不是兩手垂著待機或向前打拳。
```

### 03_反彈：動作段

```text
本張動作：成功格擋後，以銅護臂向畫面右方撥出反震。角色低重心斜弓步，前膝彎曲，後腳穩穩踏地，髖部與胸口剛從防守姿態旋向右方；近側手臂屈肘約 100 度，整個前臂從胸前有力推出去、銅護臂凸面迎向右方，白色手掌握拳且清楚露在護臂末端，注意這是屈肘的前臂推擋，不是完全伸直打拳。另一手收在肋骨至下巴之间保護身體，兩條手臂的用途和連接清楚。眼神專注，嘴角有一點得意笑意。護臂前方有一個小而集中的金色撞擊閃光；一条很短的橙色入射痕跡从右側止於銅面，另有較清楚的青綠金邊彎月衝擊弧從銅面向右上方返回，尾端由近到遠逐漸變細，以不同高低軌跡區分來襲與反彈。反彈弧是自然速度曲線，不要圖示箭頭。效果範圍不超過一個頭寬，不能遮住臉、雙手、護臂或腿。彎月與金屬碰撞火花要俐落好看，避免巨大法陣、光牆或雷射炮。
```

### 04_蓄力：動作段

```text
本張動作：護衛貓準備把接下的力道集中，蓄勢待發。採比格擋更低、更寬的馬步，兩膝向外自然彎曲，雙脚牢牢踩地，軀幹挺直略前傾。兩肘明確向兩側後方收，兩個戴護臂的前臂低低收在腰部兩旁、拳頭朝前，胸前保持開放，形成和雙臂高位格擋完全不同的輪廓。兩隻白色拳頭都要清楚可见，手肘與肩膀關係合理，不可手臂縮進身體。頭稍微低下、金色眼睛抬看右方、嘴巴緊閉，專注而有把握。兩個古銅護臂邊缘浮出微弱青金色光澤和數顆細小亮點，腳邊有一小圈很淡的氣流，腰帶尾端與黑尾略微揚起。特效必須非常克制，清楚顯示這是聚力的動作，沒有放出的能量球、沒有敵人、沒有巨大魔法陣，不要盤腿坐下或閉眼冥想。
```

### 05_受擊：動作段

```text
本張動作：角色被從畫面右方來的一擊打退，呈現可愛遊戲中的非血腥受擊反應。保持面朝右方，但胸口與肩膀向畫面左方後仰，頭略後偏，双耳稍向後壓，眼睛因疼痛短暫瞇起，嘴巴小幅張開驚呼。前腳滑退，後腳踩穩，屈膝仍準備站住，不是倒地或死亡。近側戴銅護臂的手臂彎曲、收向腹前，另一隻護臂因衝擊被帶開在胸側，兩手用途和肩肘腕連接清楚，不要用兩隻手遮住整張臉。腰帶垂帶與黑尾因慣性朝右方甩動，脚掌边只有两条短淡灰滑步線，肩旁可有少量很短的震動線。不要來襲者，不要血、傷口、破衣或破碎護臂，不要巨大的撞擊閃光或暈倒星星。相同的角色與完整服裝，只改姿勢和表情。
```
