# 噹噹：角色設定與單人主線

版本：2026-09-18，第三版（以第一版為底，收進第二版精簡得好的句子）。這份稿子新增噹噹的視角，沒有改寫球球、菲菲的既有單人主線。

## 角色設定

噹噹在村口開了一間修理鋪，修鍋、補箱角，也替人換門閂。球球常把練壞的東西搬來，菲菲則找他修過竹筒的扣環。兩人和他熟識；他不是大俠貓的徒弟，因此叫對方「大俠貓」，叫兩位朋友的名字。

那對銅護臂是噹噹自己做的。以前陪球球練招，他只顧把手架住，還是被撞得連退幾步。大俠貓替他調過站姿，又用掌心推他的護臂，讓他練習接住以後向前送。這段由動作表現，不替大俠貓另編長篇教誨。

魔塔出現後，村口接連遭魔物闖入。他留下來護住搬糧和撤離的村貓。球球先追進塔，第三天菲菲也出發了；等村貓接手守門，噹噹才進塔。他要把朋友接回來，也要弄清楚為什麼魔物總從塔裡跑出來。

他會注意地面能不能踩、重物往哪裡倒、旁邊有沒有別人。說話直接，能幫就動手；遇到不合理的要求，也會拒絕。受傷會疼，累了會坐下，不能因為擅長格擋就把每一擊都寫成毫無感覺。

### 稱呼與聲音

| 人物 | 寫法 |
|---|---|
| 噹噹 | 不加「喵」。句子直接說人、物和眼前的事，不固定用同一句口頭禪。 |
| 球球 | 每段發言以「喵」收尾；稱菲菲「師妹」、稱大俠貓「師父」、稱噹噹名字。 |
| 菲菲 | 不加「喵」；稱球球「師兄」、稱大俠貓「師父」。怕痛，但能觀察、下判斷和幫忙。 |
| 大俠貓 | 發言只用現有固定短句。動作和關心交給旁白呈現。 |
| 關主 | 保留本來的身份與立場；稱呼主角時，不把噹噹誤認成大俠貓的徒弟。 |

## 單人路線的時間安排

這是同一次魔塔事件的另一條可玩路線，不是接在球球或菲菲的通關結局之後。

- 球球：魔塔出現當晚進塔。
- 菲菲：三天後進塔。
- 噹噹：菲菲出發後，同日稍晚進塔。
- 噹噹抵達塔頂時，兩人已經在那裡。他們協助救人和撤離，正式單人戰鬥仍由噹噹完成。
- 原有落敗段落裡的無名救援者維持未指名；本稿不把所有過去的救援都算到噹噹身上。
