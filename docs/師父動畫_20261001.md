## 2. 程式怎麼改（白話）

**打包**（`tools/pack_side_motion.py`）
- 三套新條目，`sprite_box` 模式：素材單位本來就是遊戲立繪像素，腳底用 `spriteBox` 算成「立繪底邊中點」，不再另調抬高與倍率。
- 招式片段剪掉前後站著與中間定住的格子，壓到 1.35 秒（跟其他魔物同一條節奏，約 1.5～1.7 倍速）。各段剪法寫在 `KINDS` 的註解裡。
- 變身片段用**下一階段**的倍率（換階段那一刻框已經變大，`change_display`）。
- 戰敗 `death(..., late=True, max_s=4.0)`：晚一點才下載、不算就緒；長倒下上限照原速。
- 待機 `idle_from`：借第一段片段第 0 格佔位，不另出圖集（`staticIdle` 從來不畫、不下載）。
- 圖集倍率跟其他魔物一樣 1.2 倍（畫面需要的 1.2 倍）。試過 1.5 倍，總量 15 MB 左右、多三成，沒有用。

**特效**（`tools/pack_fx.py`、`src/ui/fx-layer.ts`、`src/ui/fx/cues.json`）
- 黑氣 72 格、閉關氣場 51 格整段收（來源已挑好可循環的頭尾），每 2 格取 1。閉關氣場來源背景留了一層很淡的粉色霧：打包時把「透明度低、綠不比藍多」的那層壓到兩成（金色圓環與光點不動）。
- 提示表新增三個欄位：`opacity`（濃淡）、`fadeInMs`（淡入）、`fadeOutMs` 對不循環的也有作用（播完前淡出，不會整團突然消失）；新時機 `seclude`（閉關）。收掉時從現在的濃淡開始淡（半透明的黑氣原本會先閃一下全黑）。
- 氣場的名字改用提示在表上的位置（黑氣與閉關氣場一起傳、先後不同也認得出同一條，不會重來）。

**戰鬥畫面**（`src/ui/screens/combat.ts`）
- 師父那三套沒有預設出招：這一招沒對到片段（醉拳）或圖集還沒到，就交還靜態的出招立繪。
- `enemyAuraCues`：黑氣一直有；閉關中才加閉關氣場，變身演完才出來；倒下全部收掉。
- 開打那一串（第一階段 → 第二階段 → 特效 → 第二階段招式）後面接第三階段的戰敗與招式片段（只下載不解碼，到第三階段那一刻才解）。
- 第三關的背景下載函式 `prefetchMasterMotionAhead` 放在戰鬥畫面這一塊（開局時 A 層就抓了），`netload-run.ts` 只叫它。**直接在 netload-run 引用逐格、特效那幾支的話，打包會把它們各拆成一個檔，首載程式多 158 位元組（實測），所以改成這樣**。

**逐格**（`src/ui/enemy-motion.ts`）
- 三套加進 `SIDE_MOTION_KINDS`、`STATIC_IDLE_KINDS`；第三套加進長倒下。
- `prefetchEnemyMotionAhead`：一張下載完才排下一張，離開這一局就停。`prefetchEnemyMotionLate` 多一個「只下載不解碼」的選項。

### 3.6 慢網路（0.8 Mbps／300 毫秒、冷快取）
