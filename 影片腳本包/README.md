# 影片腳本包——給 design 工具用

兩支 15 秒影片的完整腳本＋所有角色與場景參照圖。

## 內容
- `開頭影片_15秒.md`：師父走火入魔衝上塔、球球出發（5 個鏡頭，含每鏡的中文描述、動作、字幕、English prompt、該附哪幾張參照圖）
- `結尾影片_15秒.md`：師父恢復、相擁而泣、一起回家（4 個鏡頭，同上格式）
- `參照圖/`：15 張 PNG
  - `球球_官方設定表.png`——**每一鏡有球球都要附這張**（比例鐵則：頭跟身體一樣大、大圓眼、小嘴）
  - `合參表_球球與師父.png`——兩人同框的鏡頭附這張（左球球、中師父平時、右師父走火入魔）
  - `師父_平時模樣.png`／`師父_走火入魔.png`／`師父_戰敗跪地.png`／`師父_獅吼.png`
  - `球球_待機／勝利／難過／蜷縮／參上封面.png`
  - `場景_師父傳功／塔頂夜空／塔下石牢／標題畫面／勝利結算.png`

## 使用要點
1. 每個鏡頭的 prompt 直接複製 **English prompt** 段落即可；中文描述是給你核對用的。
2. 生成時把該鏡頭列的參照圖一起附上，角色長相才不會跑掉。
3. 畫風三句話：thick black outlines、flat colors with soft gradients、cute cartoon（不要寫實）。
4. 球球台詞句尾一定有「喵」；師父不加喵。
5. 另有六張「劇情定格圖」正在生成中（師父正常立繪、傳功、入魔、出發、相擁、回家路），生好會補進 `參照圖/`——拿定格圖當首尾幀能讓影片更穩。
